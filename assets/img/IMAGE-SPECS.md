# Image specs for the AI image generator

This project needs one new category banner image. Please generate it and save it
at the exact path/filename below so the website picks it up automatically.

## Needed file

`assets/img/immersive.jpg`  — banner for the "Immersive Technology & Training" category.

## Banner dimensions (applies to all category banners)

| Spec              | Value                                             |
|-------------------|---------------------------------------------------|
| Aspect ratio      | 16:6  (≈ 2.67:1, wide landscape)                  |
| Recommended size  | 2304 × 864 px  (2x / retina)                      |
| Minimum size      | 1152 × 432 px                                     |
| Format            | JPG (or PNG)                                       |
| Crop behavior     | `object-fit: cover` — image is cropped to fill    |
| Safe area         | Keep key subject centered/right; the bottom-left  |
|                   | corner is covered by a category label overlay.    |
| Corners           | Displayed with 22px rounded corners (no need to   |
|                   | bake rounding into the image).                     |

## Art direction for immersive.jpg

- Theme: immersive technology & professional training — VR headsets, virtual
  reality training, digital twin / 3D visualization, interactive learning.
- Tone: clean, modern, enterprise / commercial / civilian technology.
- Palette should sit well with the site's copper (#cb7429) on dark charcoal look.

## IMPORTANT — content restrictions

Do NOT include any military, defense, tactical, army, soldier, combat, weapon,
surveillance, or intelligence themes in ANY generated image. All imagery must be
strictly enterprise / commercial / civilian technology.

`assets/img/portable.png`, `assets/img/geofence.png`, `assets/img/cdi.jpg`,
`assets/img/dmi.jpg`, `assets/img/cyber.jpg`
