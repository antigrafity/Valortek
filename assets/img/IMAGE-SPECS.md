# Image specs for the AI image generator

Please generate the images below and save each at the EXACT path/filename so the
website picks them up automatically. All images must share a consistent visual
style (same lighting, palette, and treatment) so the site looks cohesive.

Global style: clean, modern, enterprise / commercial / civilian technology.
Palette should sit well with the site's copper (#cb7429) on dark charcoal.

## IMPORTANT — content restrictions (applies to EVERY image)

Do NOT include any military, defense, tactical, army, soldier, combat, weapon,
surveillance, or intelligence themes. All imagery must be strictly enterprise /
commercial / civilian technology.

Also do NOT include any dashboard / screen-UI / chart-on-screen visuals in ANY
image. Keep imagery conceptual and environmental rather than showing app or
dashboard interfaces.

Do NOT include people or human figures. Do NOT show physical networking hardware
such as server racks, routers, switches, network appliances, or patch panels.
When connectivity or infrastructure needs to be communicated, use abstract 3D
topologies, glass nodes, light paths, and conceptual data-flow structures.
